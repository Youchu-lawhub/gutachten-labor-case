# 法源导航

本索引提供查找路径，不静态断言任何法条当前有效。每案仍须按 `research-protocol.md` 核对官方文本、版本、时点、地域与效力。

| 问题范围 | 优先检索的规范层 | 路由提醒 |
| --- | --- | --- |
| 劳动关系及主体归属 | 劳动关系建立、特殊用工、劳动合同主体与责任的法律及司法解释 | L 判断关系；独立给付责任另检 R；关系否定不封闭全部法定责任 |
| 合同订立、期限、变更、无效 | 劳动合同法律规范及其司法解释；民事法律规范仅在依法补充适用时 | L、V、R 分别针对状态、行为效力和具体请求 |
| 工资、工时、休息休假、女职工与未成年保护 | 劳动基准及配套规范、司法解释、地方适用规则 | 请求适用 R；指令约束力可嵌 M；规范冲突走 N |
| 解除、终止、补偿、赔偿 | 劳动合同退出及保护规范、司法解释、集体规范或有效合同 | 先按真实退出路径走 E；金钱或继续履行分别以 R 承接 |
| 工会、集体协商及集体合同 | 集体劳动关系与工会规范、集体合同及其适用规则 | N 判断规范适用；M 判断组织／管理权限；个别给付仍需 R |
| 派遣、承包、关联企业、企业变动 | 特别用工、主体变更、责任承担的法律规范及司法解释 | 分开 L 关系归属和 R 法定责任；不得用“实际控制”代替规则 |
| 工伤、职业病、安全、社会保险 | 社会保险、工伤、职业病与劳动保护规范，行政法规／规章及司法解释 | 区分行政确认／基金给付 A、单位私法义务 R、侵权救济及程序路径 |
| 劳动争议仲裁与诉讼 | 劳动争议处理法律、司法解释、程序规则与过渡条款 | P 用于独立程序设问或成功救济外壳，不因案情提及法院自动扩章 |
| 证据与举证责任 | 劳动争议处理法律中的举证条款、历次劳动争议司法解释中的举证责任特别分配、工资支付与考勤记录保存规定、民事证据规则 | 按 relationship-analysis.md 锚点检索并核验争议时点版本；解释文本曾被整合改号，条号以行为时有效文本为准 |
| 个别约定、规章与强制规范冲突 | 合同规范、劳动基准、规章制度制定与适用规则、集体规范 | 先辨规范来源与性质，再依 N/V 确定对目标效果的具体影响 |

官方检索入口按案件需要从全国人大、国务院及部门、最高人民法院、地方政府／人社部门等官方网站进入。链接失效时通过发布机关官网按规范标题、文号和公布日期定位，不以搜索结果摘要代替文本。
