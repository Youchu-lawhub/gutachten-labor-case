# 方法论依据与适用边界

本技能是劳动法案例分析工作流，不是劳动法教义学的封闭分类，也不是现行法数据库。它采用“先确定法律效果、再找法源、按规范要件展开、回到事实得出结果”的方法，并把民法、刑法、行政法系列技能的工程化工作流用于任务组织；实体分析程式仍根据劳动法规范、问题效果和请求结构生成。

## 一、方法要点与适用边界

| 方法要点 | 适用边界 |
| --- | --- |
| 问题范围先于论证；诉讼成功分析通常区分程序可受理性与实体有理由性；围绕指示约束力、具体请求效果和规范条件搭建要件；依问题裁剪结构 | 境外实体法、集体制度与法院程序不得直接作为中国法结论 |
| 从设问与法律效果定位规范；同一效果可能有多个基础；事实涵摄必须对应具体要件；区分法条、事实与结论 | 既有范例年代对应的法律、司法解释或裁判观点不视为现行规则 |
| 劳动法包含私法、公法及混合规范；规范性质与具体法律后果需分层识别；不得从“违反强制规范”径直推出合同无效或个人请求权 | 学理分类是分析工具；具体后果须以适用法为准，不把理论主张伪装为制定法 |
| 私法请求不止金钱给付；履行请求、保护义务及救济性请求可按其构成基础辨析；请求权结构可帮助定位但不替代问题范围 | 请求权体系服务于私法请求；关系确认、形成效力、行政职责、程序判断等依其自身程式处理 |
| 按请求效果检查覆盖面；区分履行、金钱给付、损害赔偿、社会保险和多主体责任的不同依据 | 请求类型是漏项检查表，不是固定单元、章节或 agent；不照抄任何具体法律意见 |
| 采用可重复的工作流：设问／事实输入→路径候选→规范要件大纲→鉴定式写作→一致性校验；阶段产物彼此可追踪，确认只针对产物 | 劳动法不照搬任何单一部门法的大纲。R 的请求权三层只处理具体给付请求；劳动关系、行为效力、解除、管理权限、规范适用和行政接口各有结构 |

## 二、方法上的可检验约束

1. **可追溯**：每个终稿判断都可回指经核验的规范、具体要件和已给事实；不能只由标签或仲裁结果推出。
2. **可反驳**：大纲显式保留真实竞争路径、例外与条件；涵摄说明何种事实会改变结论，不能把有争议的分类写成既定事实。
3. **最小充分**：保留会改变用户所问法律效果的节点；题目未问的伴生请求、程序风险和裁判建议不加入正文。
4. **领域适配**：方法标签选择审查程式，制度标签帮助找法，程序范围决定外壳；三者不能互相替代。
5. **分层负责**：设问单元 U 决定完整答复与分工；请求节点 Q 保存不同法律效果；要件和证据不能自动成为单元或 agent。
6. **法源优先**：学说、教材和案例用于解释及争点发现；具体法律后果回到案件时点、地域与有效规范。

## 三、材料使用

正式执行具体案件时，以经核验的现行规范为实体法依据。用户在本任务另行提供的材料只作方法或争点线索，须经核验方可写入正文，不得当作终稿的实体法引注，也不得据未经核验的既有材料径直推出某一结论。
