# 地方数据检索路径登记表（source-routing）

> **定位**：本文件登记**无法从法律检索能力槽（一级后端）直接取到**的地方性劳动法数据 / 标准的**权威检索路径**——即"这类数据该去哪个机关、哪个入口、哪个镜像站找，怎么交叉验证，有哪些坑"。它是**导航地图（jurisdiction-agnostic）**，回答"去哪找"；具体取回的**数值**沉淀于 `local-standards.md` §二 地方参数表，回答"是多少"。两文件分工：先查本文件对应类别行锁定入口 → 运行时检索取值 → 值写入 local-standards.md。
>
> **在工作流中的位置**：W2a 识别到金额或口径依赖地方参数、W3 金额计算取值时，**先读本文件对应类别行**锁定入口，再执行 [检索协议 §6](research-protocol.md) 降级链的二级网络检索（官方网页优先），避免每次从零摸索门户。
>
> **维护纪律**：
> 1. 路径行**只在入口失效 / 发现更优镜像时更新**，数值一律不落本文件（数值归 local-standards.md，带核验日期与 90 天复检）；
> 2. 每个入口 URL 登记时须实际访问验证可达；聚合类第三方站（本地宝 / si12333 / 媒体）只作**交叉验证或线索**，不得作为唯一来源，最终以政府 / 人社 / 统计门户原文为准；
> 3. 新省份运行时命中后，其门户域名追加至 §3 省级入口清单；
> 4. 陷阱登记（§5）为实证经验，遇新坑即追加。

## 1. 工具分工与分流规则（先判断该用哪条轨）

| 数据类型 | 法律检索能力槽（一级后端） | 走向 |
| --- | --- | --- |
| 法律 / 行政法规 / 司法解释 / 部门规章**条文** | ✅ 条文检索 / 取原文（按注册能力槽契约） | 走一级后端，条文级核验 |
| 全国性部门规范性文件（如劳社部发〔2008〕3 号月计薪天数、劳部发〔1995〕309 号、劳部发〔1994〕479 号） | ⚠️ 部分可条文检索命中，部分只返文档级或检索不到 | 先试一级后端关键词反查；miss 则转二级网络检索（官方网页） |
| **地方性数据标准**（最低工资 / 失业金标准 / 社平工资 / 缴费基数 / 工伤地方标准） | ❌ 基本不覆盖（属省级政府 / 部门规范性文件 + 统计数据） | **直接走本文件 §2 对应类别 → 二级网络检索** |
| 地方裁审口径（省高院纪要 / 解答 / 人社厅仲裁指导意见） | ⚠️ 偶有收录，多为文档级 | 一级后端试 → miss 转省高院 / 人社厅官网 + 二级网络检索 |

**分流铁律**：凡"随地区 / 年度变动的数值型参数"，默认不在一级后端，直查本文件 §2；凡"条文文义"，默认走一级后端。

## 2. 数据类别 × 权威来源导航矩阵（主表）

### 2.1 最低工资标准（月 / 小时）——**多参数之锚**

- **发布机关**：省级人民政府（以省政府名义发文，如豫政〔20xx〕xx 号），依据《最低工资规定》（劳动保障部令第 21 号）。
- **国家级一站式入口**：人社部 `mohrss.gov.cn` 定期公布《全国各地区最低工资标准情况》汇总表（含各省月 / 小时标准）——**跨省速查首选**。
- **省级首选入口**：省人民政府门户网（`www.[省].gov.cn` 政策文件库）＋省人社厅官网通知公告栏。
- **常用镜像**：`waizi.org.cn`（政策库全文转载，正文可靠但附件常缺）；本地宝 `m.[城市].bendibao.com/live/gongzi/`（城市适用值速查）；地市政府门户转载。
- **交叉验证**：① 月最低工资 × 90% ≈ 失业保险金一类区域标准（可与 §2.2 反推互校）；② 本地宝城市值 ↔ 省政府原文附件区域类别表。
- **陷阱**：① 附件"行政区域类别表"常为**图片**，无法逐字读取城市归类 → 用交叉验证或找文字版，登记 [待人工核对·非阻断]；② 转载页常**不显示发文字号** → 回省政府门户原文补号，补不到则软标注；③ 各省标准**含 / 不含个人应缴社保公积金口径不一** → 正文须注明口径。
- **时效**：约两年一调（不定期）；核验生效日期，取案件争议时点的现行值。
- **派生**（一改俱改）：一裁终局金额线 = 月最低工资 × 12（《劳动人事争议仲裁办案规则》§50）；病假工资下限 = 月最低工资 × 80%（§2.6）；失业金一类标准 = 月最低工资 × 90%（§2.2）。

### 2.2 失业保险金月标准 + 可领月数档位

- **发布机关**：省人社厅（会同财政厅等），依据《社会保险法》§46 ＋ 各省失业保险条例 / 办法。
- **国家级镜像入口**：人社部 `mohrss.gov.cn` "地方动态"栏目（`/SYrlzyhshbzb/dongtaixinwen/dfdt/`）**转载各省调整通知**——找省级通知的快捷旁路。
- **省级首选入口**：省人社厅官网通知公告 / 政策法规栏。
- **常用镜像**：地市政府门户（人社局子站，如 `rsj.[市].gov.cn`）、省人社厅微信公众号。
- **交叉验证**：月标准通常 = 当地最低工资 × 一定比例（河南 90%）；**可领月数档位全国统一**依《社会保险法》§46（缴费满 1 年不足 5 年最长 12 个月、满 5 年不足 10 年 18 个月、10 年以上 24 个月）——此为国家法律，走一级后端，不属地方的数据。
- **陷阱**：① 转载页不显示文号；② 标准常**分区域类别**（一类 / 二类 / 三类），须匹配受诉地区域；③ "省直统筹参保单位"可能单列参照标准。
- **时效**：每年或随最低工资调标后。

### 2.3 上年度社会平均工资 / 社保缴费基数上下限——**社平工资为 2N 封顶之锚，缴费基数用于社保缴纳**

> **用途隔离**：本节包含两类不同数据——① 社平工资（上年度职工月平均工资）→ 经济补偿 / 赔偿金 2N 双封顶线（《劳动合同法》§47②）；② 社保缴费基数上下限 → 五险缴费基准。二者统计口径可能相同（均参考全口径城镇单位就业人员月平均工资），但**法律依据、用途和发布机关不同**，不得混用。正文引用时须分别标注用途与依据。

- **发布机关**：省统计局（公布社平工资）＋省人社厅 / 医保局 / 财政厅 / 税务局**四部门联合发文**（公布年度缴费基数上下限）。
- **国家级入口**：国家统计局 `stats.gov.cn`（分省年度数据）；人社部缴费基数口径说明。
- **省级首选入口**：省统计局官网（数据发布 / 统计公报）＋省人社厅官网。
- **常用镜像**：地市政府门户转载、主流媒体转述。
- **交叉验证**：缴费基数基准 = 上年度全口径城镇单位就业人员月平均工资；上限 = 基准 × 300%、下限 = 基准 × 60%（自洽校验）。
- **陷阱**：① **口径多样**（全口径 / 城镇非私营 / 私营 / 城镇单位），2N 双封顶（§47②）用"上年度职工月平均工资"须明确采哪个口径，登记取舍；② 媒体转述的"最新年度值"**须回官方核实**，不径引媒体；③ 四部门通知转载页常无文号；④ **"上年度"随解除时点变动**——须按案件解除年度确定适用值，非机械取最新。
- **时效**：每年年中（约 7 月）调基。
- **派生**：经济补偿 / 赔偿金双封顶线 = 社平工资（上年度职工月平均工资）× 3，封顶年限 12 年（《劳动合同法》§47②）。

### 2.4 月计薪天数 21.75 / 月制度工作日（全国统一但一级后端难检）

- **来源**：人社部发〔2025〕2 号《关于职工全年月平均工作时间和工资折算问题的通知》——取代劳社部发〔2008〕3 号（已废止）。全国统一，非地方数据，但系部门规范性文件，一级后端可能检索不到。
- **适用分期**：① 2025 年通知施行后：月制度工作日 **20.67**（法定节假日 13 天），月计薪天数仍为 **21.75**；② 2025 年通知施行前：月制度工作日 20.83（法定节假日 11 天），月计薪天数 21.75——按争议行为时点选取对应值。
- **入口**：先试一级后端关键词"月计薪天数 21.75 人社部发〔2025〕2 号"；miss 转人社部官网 / 二级网络检索取原文。
- **陷阱**：**制度工作日（20.67 或 20.83，随时段变动）vs 计薪天数 21.75（月）不可混用**——加班费 / 日工资折算用 21.75，出勤天数计算用制度工作日。

### 2.5 医疗期长度（国家 + 地方）

- **国家来源**：劳部发〔1994〕479 号《企业职工患病或非因工负伤医疗期规定》——3–24 个月，按实际工作年限 + 本单位工作年限确定。
- **地方差异**：部分省市医疗期计算有地方口径（如上海按本单位工作年限单独算法）→ 须检索受诉地有无地方规定。
- **入口**：一级后端试 → 地方规定转省人社厅官网 + 二级网络检索。

### 2.6 病假工资 / 疾病救济费下限（国家 + 地方有无）

- **国家来源**：劳部发〔1995〕309 号 §59——病假工资或疾病救济费可低于当地最低工资，但**不低于最低工资标准的 80%**（一级后端条文级可校验）。
- **地方差异**：各省工资支付条例 / 规定可能设专门标准（算法不一）→ **须先判断受诉地"有无地方规定"**；无则回落国家 80% 口径。
- **陷阱**：判断"有无地方规定"本身需检索确认，可用汇总类文章作**转述确认级**线索，但正文表述宜"截至 [日期]，在所列来源中未检索到 [省] 省级专门规定，适用国家口径"并标注核验方式。

### 2.7 地方裁审口径（省高院纪要 / 解答 / 人社厅仲裁指导意见）

- **发布机关**：省高级人民法院 ＋ 省人社厅（劳动争议仲裁指导意见 / 会议纪要 / 解答）。
- **入口**：省高院官网、省人社厅官网；一级后端"地方司法文件"检索——**多为文档级，司法解释性质的须重试或软标注**。
- **陷阱**：高院纪要**非司法解释**，不得作条文级 blockquote 校验，只能作口径来源标注；跨省差异大，须严格匹配受诉地。

### 2.8 工伤保险地方标准（一次性伤残就业补助金 / 医疗补助金等）

- **来源**：《工伤保险条例》授权**省级人民政府**规定具体标准（如一次性工伤医疗补助金、伤残就业补助金按月数计）；基数多为**统筹地区上年度职工月平均工资**（联动 §2.3）。
- **入口**：省政府门户 + 省人社厅工伤保险处专栏；条例条文走一级后端，地方月数标准走二级网络检索。

### 2.9 定性法律解释问题的地方裁审口径

- **定位**：与 §2.7（裁审口径通用入口）互补。§2.7 侧重"去哪找"的通道登记；本条侧重**何时必须检索**的触发规则与**定性争点**的特殊处理。
- **触发条件**：核心争点涉及法律解释分歧，且该分歧在实务中存在地区差异。典型场景：
  - 书面形式是否包含数据电文（电子邮件、微信记录等）
  - 加班审批制度的举证责任分配与认定标准
  - 竞业限制补偿金最低标准与违约金调整规则
  - 未签书面合同二倍工资的时效起算与仲裁前置
  - 违法解除与合法解除的认定边界（严重违纪的认定标准）
  - 劳务派遣"三性"岗位的认定口径
  - 平台用工关系认定的地方裁判标准
- **发布机关**：省高级人民法院（审判业务文件、会议纪要、解答、典型案例）；省人社厅/省劳动争议仲裁委员会（仲裁指导意见、会议纪要）。
- **入口**：一级后端"地方司法文件"关键词检索 → miss 转省高院官网"裁判文书/审判指导"栏目 + 省人社厅官网 + 二级网络检索。
- **效力定位**：高院审判业务文件、会议纪要**非司法解释**，不得作条文级 blockquote 校验；但在受诉地辖区内对中院和基层院有实质约束力，按 SKILL.md 铁律层 #3 规范权威分层第 6 层（高院裁判观点）定位，在候选规范表单独列明。
- **陷阱**：
  1. 高院解答/纪要的标题往往不直接包含法律关键词（如"劳动争议审判若干问题的解答"），须按发布日期和适用范围筛选，不能仅靠关键词命中；
  2. 部分口径已废止或被新文件替代，须确认现行有效；
  3. 跨省差异大——A 省高院的口径不能直接用于 B 省案件，须严格匹配受诉地；
  4. 经检索未在所到来源中发现专门口径的，不得以其他省份口径替代，须标注"截至 [日期]，在所列来源中未检索到 [受诉地] 专门定性口径（搜索未命中可能源于索引缺失、标题不含关键词或网站不可用，不等于不存在）"后按全国性规范分析。

**检索结果状态**（记录于台账，不得将"未检索到"等同于"不存在"）：

- **已找到**——取得明确适用的口径文件
- **未检索到**——在所到来源中未发现匹配结果（须列明所查来源）
- **来源不可达**——目标网站或入口无法访问（须记录原因与替代尝试）
- **不适用**——该争点无需地方定性口径（如纯全国性规范问题）

## 4. 派生计算链（一个数据推出多个，改一处须联动全部）

```
最低工资（月）
├── × 12  → 一裁终局金额线（办案规则 §50）
├── × 80% → 病假工资 / 疾病救济费下限（劳部发〔1995〕309 号 §59）
└── × 90% → 失业保险金一类区域月标准（地方口径）

社平工资（上年度职工月平均工资）
└── × 3   → 经济补偿 / 赔偿金双封顶线（劳动合同法 §47②，封顶年限 12 年）

缴费基数基准（= 上年度全口径月平均工资）
├── × 60% → 缴费下限
└── × 300%→ 缴费上限
```

**联动纪律**：最低工资 / 社平工资一经复检更新，所有派生线（一裁终局线、病假下限、失业金、2N 封顶）须同步重算，避免正文出现新旧值混用。

## 5. 已知陷阱登记（实证经验，遇新坑即追加）

1. **一级后端按标题检索误命中他省同名规定**——检索《工资支付暂行规定》可能误命中《江西省企业工资支付暂行规定》。**对策**：改关键词反查（如"延长工作时间 150% 200% 300%"），命中后核文档标识与发布机关。
2. **转载页不显示发文字号**——地市政府 / waizi.org.cn 转载常略去文号。**对策**：回省政府 / 省人社厅门户原文补号；补不到则软标注 [待人工核对·非阻断]，不影响数值可用性。
3. **附件区域类别表为图片**——最低工资通知的"行政区域类别表"常为图片，无法逐字读取城市归类。**对策**：用交叉验证（本地宝城市值 + 失业金 90% 反推）确认，登记 [待人工核对]。
4. **一级后端未返回施行日期字段**——部分部门规范性文件（如《工资支付暂行规定》）接口无施行日期。**对策**：以公开记载补充并标注"接口未返回施行日期，公开记载自 xxxx-xx-xx 施行，待人工核对原文附则"。
5. **媒体转述的年度数据未回官方核实**——社平工资"最新年度值"常见于新闻转述。**对策**：媒体只作线索，数值以统计局 / 人社厅原文为准。
6. **网页抓取超时**——大页面或附件易超时。**对策**：优先取 HTML 正文页而非附件；超时则换镜像站。

## 6. 时效复检纪律

- 数值型参数一律沉淀于 `local-standards.md` §二并带【核验日期 + 复核周期】；**核验日期超 90 天强制复检**（社平工资 / 失业金通常每年年中调整，最低工资约两年一调）。
- 本文件（路径表）仅在**入口失效 / 发现更优镜像 / 新增省份门户**时更新，不随数值变动。
- 受诉地 ≠ 已登记省份的，运行时按 §2 类别路径 + §3 入口清单检索该省，取回值写入 local-standards.md 对应新省小节，门户域名回填 §3.2。
