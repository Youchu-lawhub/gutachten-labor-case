# 金钱请求范围与计算检查

**角色定位**：本文件为校验参考，用于核对请求类型、计算参数与常见争议点。分析起点是义务面扫描（见 methodology/obligation-analysis.md），从义务违反推导请求权后，用本文件校验完整性。

本页只用于已确认的金钱请求，不创设请求权基础，也不提供固定金额公式。先确定请求成立路径和责任主体，再计算范围。

## 计算步骤

1. **确定计算对象**：工资、加班费、补偿、赔偿、未休假款项或待遇差额；不把不同法律基础并入同一公式。
2. **确定时间区间**：起算、截止、中断或关系变动日期；跨修法时分段。
3. **确定基数**：逐项列出计入／排除项目、平均期间及依法适用的特别口径。
4. **确定算法**：工作年限折算、倍率、上下限、地域／年度标准、扣除或已支付金额；每项须对应经核验规则。
5. **展示结果**：给出公式、参数来源、分段过程、舍入方式与总额。事实不足时给条件式结果，不以仲裁数额反推参数。
6. **复算**：将分段小计相加并独立反算；校验币种、单位、日期和请求范围。

金额是 R 的责任范围节点，不另设分析单元；只有用户另问独立的计量规则或计算期间时，才依设问划分。

## 高频请求的计算锚点

| 请求类型 | 关键参数 | 常见陷阱 |
| --- | --- | --- |
| 经济补偿 | 工作年限×月工资（《劳动合同法》第47条） | 2008年前后分段计算；高薪三倍封顶及年限上限（12年）；月工资前12个月平均 |
| 违法解除赔偿金 | 经济补偿×2（第87条） | 与继续履行的选择关系；赔偿金不再另付经济补偿 |
| 未签合同二倍工资 | 每月工资×未签期间（第82条） | 起算点（用工满1个月次日）、上限（11个月）、时效起算争议 |
| 加班费 | 工资基数×倍率×加班时长（第44条） | 工时制度（标准/综合/不定时）；补休规则（休息日可补休、法定休假日不可）；基数口径 |
| 未休年假折算 | 日工资×未休天数×300%（《职工带薪年休假条例》第5条、《企业职工带薪年休假实施办法》第10条） | 日工资=月工资÷21.75；**300% 含正常工作期间工资**；用人单位已支付正常工资的，额外支付 200%（非 300%）。以日工资 100 元、5 天未休且正常工资已付为例：总额 1,500 元，已付 500 元，额外应付 1,000 元 |
| 停工留薪期工资 | 原工资福利不变（《工伤保险条例》第33条） | 一般不超过12个月，特殊情况可延长；"原工资"口径按当地规则 |
| 待岗生活费 | 当地最低工资×比例（各地规定） | 第一个工资支付周期按原标准；之后按比例，各地比例不同（如北京70%、上海100%） |

## 2008年前后分段计算（经济补偿）

《劳动合同法》2008-01-01 施行，经济补偿计算须分段：

- **2008年前**：按当时有效规则（《劳动法》第28条、《违反和解除劳动合同的经济补偿办法》劳部发〔1994〕481号），协商解除和单位解除事由不同，上限规则不同
- **2008年后**：按《劳动合同法》第47条，统一规则，高薪三倍封顶12年
- **跨期计算**：2008年前工作年限按当时规则，2008年后按新法；《劳动合同法》第97条过渡条款

不得用单一公式裁断全部跨期工作年限。
