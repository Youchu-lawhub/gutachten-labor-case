# 报酬、工时与休假请求提示

**角色定位**：本文件为校验参考，用于核对请求类型、计算参数与常见争议点。分析起点是义务面扫描（见 methodology/obligation-analysis.md），从义务违反推导请求权后，用本文件校验完整性。

本页帮助发现请求节点，不预设请求、法源或结论。先按用户设问建 U/Q，再核对适用规范。金额始终是对应请求的责任范围。

| 事实／问题信号 | 可能的独立法律效果 | 结构提醒 |
| --- | --- | --- |
| 工资、奖金、津贴、停工待遇 | 支付特定期间报酬 | R：主体／工资标准／应付期间／到期；奖金另核验制度或约定条件 |
| 加班、值班、调休 | 支付加班报酬或确认休息权利 | R：工时制度、安排或可归责、工作日类型、证据与补休规则分别匹配规范 |
| 年休假、病假、事假、休息日 | 安排实际休假、支付依法产生的折算款项 | 实际休假与未休折算是不同效果；不能互作当然替代；病假工资按当地规定及工龄分段；事假无薪除非另有约定 |
| 待岗、停工、停产 | 支付待岗期间生活费 | R：非因劳动者原因的停工停产、第一个工资支付周期按原标准、之后按不低于最低工资一定比例（各地不同） |
| 未签书面劳动合同 | 订立合同、特定期间二倍工资或关系／类型确认 | 只有被问的效果进入；各自起算条件、期间与排除规则不同 |
| 工资差额或基数有争议 | 补足对应给付 | 核对可计入项目、适用期间、变动节点、证明来源并反算 |
| 餐补、交通补贴、通讯补贴 | 支付约定或制度规定的补贴 | R：约定或规章制度依据、发放条件、扣减规则；非工资性补贴不计入加班费基数时须有依据 |

对给付请求依 R 的“已产生（含责任范围）—未消灭—可行使”结构，抗辩按性质归层：产生障碍（权利未发生的抗辩，如要件否认、合同无效）并入第一层；清偿、抵销、免除、和解等权利已消灭的抗辩在第二层；仲裁时效等权利阻止的抗辩一律在第三层——时效只阻却行使、不消灭请求权，禁止在第二层提及或检验时效。程序前置（仲裁前置、受案范围、管辖）依 P 程式或在行使层交叉引用。未触发的抗辩只作必要简式处理。
