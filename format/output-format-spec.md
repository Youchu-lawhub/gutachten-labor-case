# 输出格式

报告结构以 examples/canonical-report-template.md 为唯一权威，内在程式以 methodology/standard-frameworks.md 为准。排版不能改造分析内容。

Markdown：报告H1→多单元部分H2→（一）大纲／（二）正文H3→程式H4→要件H5→子要件H6。单单元可省略部分层并整体上移。再深用加粗段头，不能使用七个以上 #。大纲用编号树，正文同编号，必要规范就地引注。短报告不强制目录，不设最低字数，不默认十章咨询式前后言。

Word按用户要求生成；默认A4，页边距约2.5cm，正文宋体12pt、1.25倍行距、首行缩进2字符，标题黑体15/14/12pt按层级，法条引用楷体，页码居中。可用字体替代不得缺字；目录按篇幅和用户需要。Markdown H1-H6映射Heading 1-6，脚注转原生脚注，过深层级为加粗段头。若转换后不能渲染检查，如实说明未做视觉核验。

引用只摘必要原文，页面规则不要求每条全文展示。格式选择可在交付后询问一次，非法律分析确认闸。

`verification-log.md` 工作目录版（含审计字段，schema 见 references/research-protocol.md §7）是运行时产物，仅供内部核验，不直接进入报告或 Word 转换。W4 审计完成后按 references/research-protocol.md §7.4 从中派生**三栏精简核验记录**（依据来源 / 核验时间 / 核验结论），作为报告末尾标准节随正文一并交付、一并转换；正文引用位置不重复列同一规范。
