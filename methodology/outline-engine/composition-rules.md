# 复杂案件的组合与依赖

## 1. 五种关系先于章节排序

| 关系 | 组织方式 |
| --- | --- |
| 同效果多依据（竞合／择一／补充） | 同Q分别检视依据，合并法律后果，不按法条派agent |
| 并列不同效果 | 保留各Q的完整树；适合独立答复则分U，概括救济设问可同U分子请求 |
| 主位／备位救济 | 绑定同U与负责agent，明确触发备位条件；互斥效果不能累计 |
| 先决依赖 | 仅服务于某被问给付、未被独立问则内嵌为枢纽；独立被问或自身即终点则建独立U／脊，接口一次论证、准确引用；多脊并存时结论可脱钩，不强行绑定 |
| 反请求／抵销或防御 | 根据防御功能定位；反请求本身需要成立、未消灭、可行使及可抵销条件，不能只把金额机械扣掉。劳动争议中常见反请求类型：单位主张劳动者返还多付工资、赔偿培训费、支付竞业违约金、赔偿因未交接造成的损失——每一反请求均须独立走完整 R 三层检视，不因"反请求"身份简化。抵销须分别确认双方请求均已产生、未消灭、可行使且种类相同（金钱对金钱）；劳动争议仲裁中抵销抗辩的可接受性依程序规范判断，不得径以民法抵销规则替代。反请求与主请求事实基础高度重合时（如双方各自主张对方违约解除），可同 U 内分别展开两棵 R 树，共享共同事实前提，但各自独立得出结论。 |

请求节点Q的完整性不因同agent而丧失：继续履行、期间工资、备位赔偿分别有自己的依据和条件。同一工资请求的发生、期间、基数和扣减则不能误拆成四个Q。

## 2. 多主体与责任模式

以“同一给付的义务人及责任基础”建立子树，不按企业数量自动划U。每个相对人先定角色：劳动关系主体、法定责任人、承继者、个人经营者、侵权人、保险机构。分别核验归责规范，标清连带、补充、按份、替代或独立责任及期间；程序当事人资格另审。

支付一笔债务不等于每人各支付一次。责任扩张不自动确认多重劳动关系；没有劳动关系的法定责任也不能被L否定提前截断。年限承继与主体责任是不同节点。

多个同类请求权主体（如被同一次裁员解除的多名劳动者）可共享同一先决枢纽（如解除合法性、集体规范效力），该枢纽一次论证、各主体准确引用即可；但各主体的请求权仍须独立展开、按各自期间基数独立计算，不合并成一个抽象请求权，也不因共用枢纽就把不同主体的不同请求混为一谈。

## 3. 时间、人员与规范分段

状态、主体、契约、工资、政策及法律变化时分别标期间。只有适用依据或决定性事实变更才分段；每月支付不自动需要每月一U。

集体性争议且事实／规则同构时可共享树，人员参数分别列示；存在不同身份、解除事由、工作期间或保护状态时分支。不能凭同一单位作一揽子实体结论。

变形题仅对变化节点重新涵摄并说明影响，未变共同结论引用；不复写全部背景。更换诉讼请求需重新核scope和独立效果，不只是替换结论措辞。

## 4. 公私法接口

工伤认定、劳动能力鉴定、基金待遇、社保征缴、劳动监察等分清事项及相对人；只有具体请求需要的决定才作为依赖。前置决定未取得时，说明该节点未解决，不跳到假定已认定；也不能因为行政程序未决就抹除与其无关的请求。

独立问行政合法性或机关履行时，A单元应接行政法专属程式。独立普通民事侵权、追偿等用对应R责任基础，必要时调用可用民法技能；不以“劳动领域”为理由省略已授权独立问题，也不默认展开未被问的外部领域。

## 5. 派工与循环校验

主线程依据U设负责者，前置结论归指定单元／共同节点拥有者，无依赖U并行，依赖U先研究独有法源后等待接口再决定涵摄。单元数超过容量分批。

图出现循环时检查：是否把同一节点重复建成两个Q，或把主备触发关系误画成先决；先选决定性状态／规范节点并合并共同前提，不能让agents互相等待或各自猜前提。

接口必须限定主体、期间、规范版本、事实版本和确定性。条件性前提在下游仍条件性，不能在整合时变成已查明。主线程核对所有U实际覆盖用户设问及救济互斥，不能只拼接文稿。
