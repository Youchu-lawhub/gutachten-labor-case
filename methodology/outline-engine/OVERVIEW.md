# 劳动法大纲生成引擎

目的：将具体设问转成可直接写作的规范要件树。它不是劳动法章节大全，也不是调用固定模板后填事实。

输入：已确认U/Q、共享事实、目标效果、scope、领域和责任结构，以及W2a候选规范及实际取得的文本。

顺序：

1. 目标效果定位答案规范，区分规范功能；
2. 从适用规范原文与必要解释提取 AND／OR、例外／再例外、转介、限制、期间和后果；
3. 选择 standard-frameworks 中主程式，嵌入必要状态／效力／权限／规范适用子程式；
4. 依 composition-rules 处理竞合、主备、共同前提、多主体与时间；
5. 事实映射与比例裁剪；
6. 按 canonical-report-template 组装每U的大纲，与预定正文编号对应；
7. 反向覆盖：每个被問目标有节点；每个保留节点有改变答案的理由。

必读 [生成规则](generation-rules.md) 与 [组合规则](composition-rules.md)，再读 [节点与验证](node-schema-and-checks.md)。模板的法律条件与本案规范冲突时依规范重建；不把未经核验的既有材料当作法源实时校验。

输出：逐要件树、规范对应、事实映射、未定节点、核心解释问题及U依赖。所有节点一律以待证命题呈现，不预设结论（见 generation-rules.md §7）。W2b确认的是树本身；派工规模由U而不是树节点数决定。标准程式与模板分别只有一个权威源，工作流不再维护另一套标题树。
