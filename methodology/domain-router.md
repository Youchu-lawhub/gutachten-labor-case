# 劳动法问题域识别与路由

本路由是组织法律分析的设计模型，不声称是穷尽或唯一的劳动法学科体系。以被问的法律效果为主轴，以制度领域、关系结构和程序范围为参数。学理上的教义学构造是要件发现与解释资源，不自动成为本案规则。

## 1. 三个层级：事实F、法律问题Q、分析单元U

- F 是行为、状态及期间，如招聘、调岗、拒绝到岗、停薪、解除。一个F可能关联多个Q，不能见到一个事实就新增一个请求。
- Q 是最小完整法律效果问题，如是否存在关系、某指示是否约束、能否请求某给付。同一个Q可有多个竞争法源，也可嵌入其他程式的先决节点。
- U 是用户需要独立回答的设问／完整救济簇，也是报告部分和agent的分工单位。一个U可含多个Q，特别是主备救济、反请求或相互紧密关联的请求，但必须保留各Q的规范与要件，不混成一个大结论。

先问“这个节点能否独立回答用户要求的法律效果”，再决定U。不以法条数、主体数、请求族数或元类型数计算agent。U与Q关系及融合条件见 problem-units.md。

## 2. 主轴：被问的法律效果

| 标签 | 设问原型 | 主程式入口 | 易混淆边界 |
| --- | --- | --- | --- |
| L 关系／地位／状态 | 是否属于劳动者；与谁、何时存在关系；是否已是某种合同状态 | 主体适用→成立／状态改变规范→实际事实→归属与期间 | 请求签订无固定期限合同是R；状态已依法形成是L；关系因某次解除消灭否要嵌E |
| V 法律行为成立与效力 | 合同、条款、变更或和解是否成立、生效、可撤销、部分无效 | 行为内容→成立→生效／障碍→权利行使→效果 | 规范来源和对个体的适用另用N；给付后果另为R |
| E 解除／终止 | 表示或事件是否以及何时使关系结束；解除是否违法 | 构造→表示／事件→具体法定通道及限制→行使程序→效果 | “违法”与关系当然未终结不能直接画等号；补偿赔偿R承接 |
| M 权限与约束力 | 单位可否询问、监控、调岗、安排工时；劳动者是否须服从／可拒绝 | 权限来源→边界→具体行使→约束／拒绝效果 | 指示有约束力不直接推出可强制履行或拒绝即严重违纪 |
| N 规范适用与效果 | 集体合同、规章或基准能否适用；规范冲突；违反某规范有何私法后果 | 来源性质→制定／成立→适用范围→效力／冲突→具体效果 | “强制性”不直接推出无效、个人请求权或全部连带责任 |
| R 特定给付请求 | 要求支付、安排工作、休假、签约、交付证明、停止侵害、返还或容忍 | 请求权已产生（成立＋范围＋产生障碍）→未消灭→可行使 | 非金钱亦为R；金额是范围；继续履行不能只写解除效力 |
| P 程序判断 | 能否受理、救济路径、裁决性质、期限、当事人、执行 | 具体程序对象→程序条件→适格／路径→效果 | 成功起诉一般是U的程序外壳，不自动另U |
| A 公法／行政接口 | 是否须工伤认定、机关应否给付待遇、是否补缴、行政行为如何救济 | 确定公法对象与义务人→程序及实体行政程式 | 单位支付待遇或损失R不等于基金给付A；不能将所有社保争议一概行政化 |

标签为主审查目标，并非严格互斥的事实类别。E是终结关系的专属效力程式；其他形成权依对象嵌V或M及其权利行使条件。N与V可组合：例如先审集体合同成立，再审其规范对某人的适用及工资请求。不要把八标签直接变成每案八章。

被问效果本身即效力或状态（解除是否有效、关系是否存在、指示是否约束、条款是否生效）时，该 E／L／V／M／N 程式的终点就是此效力或状态判断，不必然降格为某给付请求权的前提；劳动法上解除效力常是独立的确认之诉终点，与请求权考问同等重要，勿以“一切落到请求权”的民法惯性把它强行改写为给付脊。仅当题目以请求权式发问、或该效力状态确系被问给付的成立或消灭前提时，才作为枢纽内嵌于 R。同案可并存多脊（如既独立问解除效力、又独立问关系归属），各脊结论互不绑定、可脱钩。

## 3. 第二轴：制度领域发现表

可同时命中多域，只加载为设问服务的部分；每域可以生成不同主程式。

| 领域 | 典型问题及覆盖方向 | 常用主程式／子模块 |
| --- | --- | --- |
| D1 主体、身份、关系与归属 | 合意／实际用工、特殊身份、招用代理、企业或关联单位、承包派遣平台 | L；给付或用工主体责任R |
| D2 合同形成、期限与延续 | 书面合同、试用期、固定／无固定、续订、自动延续、签订文本 | L/V；缔约履行及二倍工资R |
| D3 规范来源、基准与冲突 | 法律、行政法规、集体合同、规章、个别合同、习惯；强制／任意；适用范围 | N/V；嵌入R/M/E |
| D4 劳动履行与组织管理 | 工作内容地点时间、调岗调薪、休假指令、停工停岗、拒绝劳动、履行障碍与风险 | M/V；工资R或解除E |
| D5 报酬、休息、福利与平等 | 工资奖金加班、病假年假、停工期间、同工待遇、休假履行 | R；M/N/L前提 |
| D6 关系退出与救济 | 协商／单方解除、裁员、法定终止、保护／顺延、补偿赔偿、继续履行及期间工资 | E；R主备救济簇 |
| D7 劳动保护、人格与伤害 | 职业安全、职业病、性骚扰、隐私监控、歧视（民族、种族、性别、宗教信仰、残疾、传染病病原携带、年龄等，《就业促进法》第3条）、女职工保护（孕期、产期、哺乳期特殊保护及解雇限制，《女职工劳动保护特别规定》）、劳动者或第三人损害 | M/N/R；工伤A接口、普通民事R |
| D8 社会保险与保障 | 征缴、待遇核定、基金支付、不能补办的损失、单位替代责任、追偿 | A/R，按对象而非题名分流 |
| D9 劳动者义务、竞争与损害 | 忠实保密、竞业约定解除、培训服务期、违约金、单位损失、返还 | V/M/R，双向请求分清 |
| D10 集体组织与协商参与 | 工会、职工代表、民主程序、集体合同、组织权限、参与、组织权利救济 | M/N/V/R/P，不将域外集体共决制度概念直接移植为中国法规则 |
| D11 责任扩张与主体变动 | 关系承继、连续年限、派遣承包、连带／补充／清算／追偿责任 | L/R子模块；多主体不等于多重关系 |
| D12 程序及执行 | 仲裁前置、时效、管辖、终局救济、请求变更、追加、证据、执行 | P或程序外壳，按实际设问裁剪 |

发现不在表中的制度，仍从其法律效果找主程式；记录新增领域及规范，不为了扩表自动扩案。缔约前歧视或损害、无劳动关系的法定用工责任不能因L否定而全部阻断R。

## 4. 第三轴：实体与程序范围

`scope=substantive | procedure | success`。主体在真实诉讼中的证明状态另用`facts=given | disputed`，不能把success等同disputed。

- substantive：只做被问实体效果，必要实体相关期间仍在该节点；
- procedure：P/A中的特定程序；
- success：适格程序条件→所请求实体效果，程序是同一U外壳；题目假定受理的部分简式处理。

是否进入行政、普通民事或劳动争议程序，依相对方、请求内容和法定受案规范，不仅凭涉及“劳动”命名。读 procedure-scope.md。

## 5. 分流算法

1. 锁定原设问与目标效果Q；没有明确设问，W1先提出最小范围，不做全领域扫描。
2. 确定义务人／行为人、方向、行为或期间以及scope，识别共同事实F。
3. 用上表选主程式；多种程式仅标为主／嵌入／备位，不能平铺。
4. 选择领域标签D及关系结构（个别／集体、多主体／承继、特殊用工），用于找法及要件提示。
5. **请求权完整枚举**：按已选领域标签，逐一扫描对应 claim-types/ 文件的全部请求节点（见 SKILL.md §4 按需加载表）。已纳入设问的标记"已覆盖"；事实已触发但未纳入设问的标记"伴生请求"并说明纳入或排除理由。扫描结果传递至 W2a 候选规范表。
6. 对每个前提问：被独立问及吗？若否嵌入；若是设独立U并建立依赖。多个Q如果主备、反请求或不可分的救济簇，可同U内分别检视。
7. 区分同效果竞争规范、并列不同效果、备位排斥、按时间分段和多主体责任，调用composition-rules。
8. W2a核定候选规范，W2b从有效规范生成要件树；反向检查每个节点如何改变回答。不能改变答案或不在范围的枝节删去。

## 6. 常见误路由

- 未签合同可能触发签约、二倍工资、状态确认，只有被问的目标进入；同一事实不等于自动三个U。
- “工龄连续”通常是范围前提，不与关联用工责任等同。
- 出具证明R与未出具造成损害R是不同请求节点；前者不以损害为必要条件。
- 请求休假、未休折算、拒绝休假后的纪律后果不同；题目问哪个就沿哪个目标组合。
- 因拒绝调岗而请求解除赔偿：R产生层内可嵌E→M→N/V，不是五个agent。
- 承包经营招用：L主体归属与R法定责任分开；无劳动关系不等于无法定给付责任。
- 继续履行与期间工资分别是行为与金钱效果，保留各自要件；可分U依赖，也可在用户概括救济的同U中并列Q；与备位赔偿绑定选择关系。
- 集体规范产生工资效果可嵌N；题目独立问工会权限或规范效力才独立U。
