# 真正争议事实的证据分析

## 1. 触发判别（题目要求优先）

题目出现下列任一情形时，必须进入证据流程，且该题目要求优先于其他文件中的范围抑制规则：

- 题干明确区分“无争议／有争议事实”，或以“争议：”“原告主张…被告抗辩…”等呈现互斥事实主张；
- 设问要求“作出（可供实施的）判决、裁定或裁决”；
- 设问直接询问争议事实由谁举证，或要求先证据裁判再入实体。

上述情形均不出现、事实全部作为既定前提给出时，题目事实直接使用；不因“如何判决”字样把纯教学鉴定题改成证据调查报告，也不因现实中可能有争议而制造争议。两类指示各有适用域，不得互相挪用压制度；判别有疑时以设问文字为准。程序成功外壳（scope=success）与证据分析仍是不同选项，仅在题目触发时叠加。

## 2. 流程

先分别记录双方主张和证据来源；假定请求方主张为真，检查其是否已足以满足具体规范。即使全真也无法成立的，无须继续调查无关事实。可成立才进入：

1. 事实分类：列无争议事实（直接作为涵摄前提）与争议事实（逐项对应待证规范节点）；
2. 证明责任分配：默认“主张权利者就权利基础要件举证”；劳动争议的特别分配按下文锚点及其时点版本适用，不得泛化为用人单位对一切事项举证，也不得要求劳动者证明单位掌握管理的外部事实；
3. 证据评价：直接证据证明力、间接证据链叠加与反证、高度盖然性标准；证据由一方掌握且无正当理由不提交的，依《劳动争议调解仲裁法》第6条"承担不利后果"——不利后果是梯度性的：对方就该事实的主张具体且可信时，可以认定该主张成立；主张本身模糊或明显不合理的，仅作对该持有方不利的事实推定，由仲裁庭或法院依经验法则判断，不得一律"认定对方主张为真"；证人利害关系、证据形成时间与案件进程的合理性逐项审查；
4. 真伪不明处理：由负担证明责任方承受不利；证据尚未穷尽不能把缺证直接写成“已证明不成立”；条件结论须保留其前提。

## 3. 劳动争议举证责任常用锚点（使用前必须按案件时点核验版本）

- 《劳动争议调解仲裁法》第6条：主张者举证；与争议事项有关的证据属于用人单位掌握管理的，用人单位应当提供，不提供的承担不利后果；
- 法释〔2001〕14号第13条（及其后历次劳动争议司法解释整合文本中的对应条文）：因用人单位作出的开除、除名、辞退、解除劳动合同、减少劳动报酬、计算劳动者工作年限等决定而发生的劳动争议，由用人单位负举证责任；
- 法释〔2010〕12号第9条：劳动者主张加班费的，应就加班事实的存在举证；劳动者有证据证明用人单位掌握加班事实存在的证据而不提供的，用人单位承担不利后果；
- 《工资支付暂行规定》第6条：用人单位须书面记录支付劳动者工资的数额、时间、领取者姓名及签字，并保存两年以上备查——考勤与工资记录超过保存期间不能出示的不利后果范围，须按争议时点核验；
- 民事诉讼法及证据解释的通用规定：待证事实范围、自认、高度盖然性标准及特殊证明要求。

历史案例须核验裁判或争议时点实际有效的解释文本（文号与条次可能已被整合改号）；条号存疑时以规范内容记载并按 references/research-protocol.md 核验，不得凭记忆定条号。

## 4. 报告内位置

证据处理默认放在所属要件的涵摄中，不另设“事实、举证、风险”三章；但题目要求先做争议事实分类并分配举证责任、再进入实体并作出判决的，该单元内“事实分类→证据裁判→实体涵摄→裁判主文”的次序是题目要求，不属被禁止的增设章节。布局见 examples/canonical-report-template.md 之“判决型形态”。单位掌握材料的提交义务不能泛化为全部劳动争议举证责任倒置。
